The problem

Chats in one long list don't scale past one task.

In a chat app, every conversation for every project lands in the same list. Run two agents on one repo and they edit the same files. Ask one to build something big and you're reading a wall of text, hoping it's right.

Monaged gives each project its subprojects, each subproject its agents, and each agent its own branch and worktree. They work side by side, and you see the state of everything at a glance.

See it work

A bug fix, then a feature from one sentence.

An agent fixes a failing test and gets a 5/5 review. Then the pipeline researches, verifies, plans and builds a feature with two builders in parallel. Recorded from the real app, sped up.

What it does

Everything around the agent, so you can trust what it did.

Claude Code does the work. Monaged organizes it, runs it in parallel, checks it, and merges it on your rules.

Projects, subprojects, agents

A tree for all of it. Each agent gets its own git worktree and branch, so parallel agents never touch each other's files or your checkout.

A pipeline that asks first

Research, two verifiers, a plan, then up to ten builders in parallel and an integrator. Large or risky plans always wait for you.

Review with reasons

Every turn gets a diff, a short summary and a 1–5 confidence score from your tests plus a skeptical review, always with the why.

Agents that coordinate cheaply

A shared board for contracts and decisions, file claims that warn about overlaps, and a librarian that answers before anyone gets interrupted.

Merges on your rules

develop, acceptance, main, each with its own rule. A merge queue with CI status, and pull or merge requests through gh and glab.

Budget-aware

Your weekly usage and Monaged's share of it, caps per subproject, and cost estimates on plans. Automatic work pauses before your limit.

Undo anything

Every turn is checkpointed. Roll a worktree back to before any message, undo the rollback, or replay an agent's work turn by turn.

Secrets stay secret

Environment variables encrypted with Windows DPAPI. Agents see names, not values, and values are masked everywhere Monaged shows text.

Native and keyboard-first

Built on GPUI, the UI framework behind Zed. Ctrl K for everything, shortcuts you can change, four themes, and Zed one click away.

The pipeline

From a sentence to a merged feature, and you decide when.

Describe what to build. A researcher reads the code, two verifiers check its report, a planner splits the work into parallel workstreams with contracts between them.

  • Plans show their size, risk flags, confidence and an estimated cost.
  • Migrations, auth, data, public APIs and security always wait for your approval.
  • Auto mode answers questions and starts small, confident plans by itself.
  • Builders work in parallel; an integrator merges them and runs the tests.
Review

A score you can argue with.

Agents are confident by nature. Monaged's score comes from evidence: your project's tests, and a short review asked to find what's broken.

  • Failing tests cap the score at 2, no tests at 4.
  • Every score lists its reasons and the concrete issues found.
  • Comment on diff lines and send them back to the agent in one go.
  • Summaries and reviews run on Haiku: cheap, and optional.
How it works

Your Windows desktop, Linux where the agents run.

Monaged is a native Windows app. Agents run inside WSL through the Agent Client Protocol, each session in its own worktree. Nothing runs in anyone's cloud but Claude itself.

Before you start

What you need.

Windows 10 (version 2004 or later) or Windows 11, x64
With virtualization turned on, which most PCs have by default.
WSL 2 with Ubuntu
The setup guide installs both if they're missing (one administrator prompt and usually a restart).
A Claude account
A Claude Pro or Max subscription, or an Anthropic Console account with API billing. Agents use your own account.
Optional: Zed, gh, glab
Open worktrees in Zed with one click; create pull and merge requests and see CI status on GitHub and GitLab.

FAQ

Questions.

Is Monaged made by Anthropic?

No. Monaged is an independent project. It runs Claude Code through the open-source claude-agent-acp adapter and the Agent Client Protocol. Claude and Claude Code are trademarks of Anthropic.

What does it cost?

Monaged is free. Agents use your own Claude subscription or API account, and Monaged shows how much of your week it's using, with a cap you choose (25% by default).

Why WSL?

Claude Code, git worktrees and your toolchains work best on Linux, and WSL gives each agent a real Linux environment while you stay on your Windows desktop. Monaged handles the bridge.

Does it send my code anywhere?

Only to Claude, the same way Claude Code does when you use it directly. Monaged itself has no backend and no analytics. Update checks go to GitHub's release page.

Windows says it protected my PC when I run the installer.

The installer isn't code-signed yet, so SmartScreen warns about it. Click More info, then Run anyway. Every release lists SHA-256 checksums you can compare.

Can I use it at work?

Yes. Monaged is source-available under the MIT license with the Commons Clause: use it for anything, change it and contribute. What you can't do is sell Monaged itself, or a service that's mostly Monaged.

Other agents than Claude?

Monaged speaks the Agent Client Protocol, so other ACP agents can be added as profiles in Settings → Agents. Claude Code is the one it's built and tested with.
